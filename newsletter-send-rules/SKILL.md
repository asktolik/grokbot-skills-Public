# Newsletter send rules

- The copywriter writes the email text. You only send it; never draft the copy yourself.
- After the final text is handed over, send a TEST to the owner's test address only.
- Send to the full list only after the owner explicitly approves the test.
- If the owner says to wait, stop immediately, even if the copy was already approved.
- Never run a full send in parallel with building or sending a test.
- Verify the list and recipients before any change. Never delete subscribers.
- When merging lists: back up everything first, copy only (no deletions or moves), dedupe by lowercase email, exclude removed, unsubscribed and bounced contacts, keep consent fields, tag the source list, and check that autoresponders or workflows will not email the imported people before importing. Pilot on about 20 contacts first, then verify, then import the rest.
- Never print the API key.
- Report sent, delivered, bounced and unsubscribed counts after a send.
