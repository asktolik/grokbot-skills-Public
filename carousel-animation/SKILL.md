# סקיל אנימציית קרוסלה (צוות)

## צינור
עורך הווידאו ← QA ← תיקיית "מוכן" ב־Drive ← וואטסאפ לבעלים דרך התפעול. **אין פרסום בלי אישור של הבעלים במילים שלו.**

## שלבים
1. **תמלול הקרוסלה:** `slides_text.md`, כל הטקסט מכל שקופית מילה במילה. זה המקור היחיד לטקסט על המסך ולקריינות.
2. **קונספט:** `CONCEPT.md` עם מבנה (הוק ← סיבוב לכל שקופית ← סיום עם לוגו API Hub והקמע), קצב והערכת קרדיטים. **שולחים לאישור לפני שמוציאים קרדיט.**
3. **סגנון:**
   - 2D על רקע כהה. צבעים כמשתנים: נייבי `#0A0B1E`, ליים `#C6FF3D`, לבן `#F6F6F0`. פונט Heebo Black.
   - הקמע הרובוט שלנו, לא הדמויות של היוצר.
   - כרטיסי "סיבוב" עם מילת הדגשה בליים.
   - חיתוך כל 2–2.5 שנ׳, אירוע בתוך הסצנה כל 0.15–0.3 שנ׳, ווש + פלאש בכל מעבר, 120 BPM על הביט.
4. **שקופיות מקור:** מותר להציג אותן בתוך מסגרת עם זום ופאנץ׳, אבל רק עם תגית קרדיט ליוצר לאורך כל הסרטון.
5. **נכסים ב־API Hub:** אותו `X-Tag` לכל העבודה.
   - קריינות: `/v1/ai/voice` בקול המשובט של הבעלים (voice id מהזיכרון, לא לכתוב אותו בקבצים משותפים), עם חותמות זמן למילים.
   - מוזיקה: `/v1/ai/music`, קודם estimate.
   - תמונות קמע לפי הצורך.
   - **הערכת עלות לפני הוצאה.** מעל 500 קרדיטים צריך "מאשר עלות" מהבעלים.
   - בסוף בודקים עלות בפועל ב־`/v1/usage?tag=`.
6. **רינדור מקומי:** Pillow + ffmpeg, 0 קרדיטים, 1080x1920, 30fps, H.264 High, bt709, faststart.
7. **מיקס:** קול ב־-16 LUFS, מוזיקה בערך 20 LU מתחתיו, fade-out בסוף, limiter.
8. **QA:**
   - LUFS, טקסט מול `slides_text.md`, כתוביות מול ASR, הגייה, קצב ויזואלי, קרדיט, מפרט טכני, גיליון פריימים.
   - דוח `QA_report_rN.md`. מעבר רק ב"עבר" או "עבר עם הערות".

## אסור
- להמציא CTA, מחיר, קופון או שם על המסך. קופון רק אם הבעלים נתן אותו במפורש לעבודה הזאת.
- לכתוב מפתחות API, voice id, טלפונים או מזהי Drive בקבצי הסקיל.
